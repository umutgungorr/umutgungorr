### 💻 Instant CLI Execution (Zero Installation)

You can run any of my CLI tools directly via `uvx`:

```bash
# Unmask Docker proxies and inspect who holds port 3000
uvx porttree 3000

# Terminate an entire zombie process tree holding port 3000
uvx porttree free 3000 -y

# Deduplicate noisy CI logs and suppress healthcheck floods
uvx logshrink -- npm test

# Check documentation for broken links and dead image anchors
uvx deadlinkfinder check docs/
```
