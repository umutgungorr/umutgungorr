### 💻 Instant CLI Execution (No Install Needed)

You can run any of my CLI tools directly via `uvx`:

```bash
# 1. Unmask Docker proxies and see which process holds port 3000
uvx porttree 3000

# 2. Kill a zombie process tree and reclaim the port safely
uvx porttree free 3000 -y

# 3. Suppress noisy terminal logs and deduplicate repetitive outputs
uvx logshrink -- npm test

# 4. Check documentation for broken links and dead image anchors
uvx deadlinkfinder check docs/
```
