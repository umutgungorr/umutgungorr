### 💻 Instant CLI Execution (Zero Installation)

```bash
# 1. Unmask Docker proxies and see which process holds port 3000
uvx porttree 3000

# 2. Terminate an entire zombie process tree cleanly
uvx porttree free 3000 -y

# 3. Deduplicate noisy CI terminal logs and suppress repetitive floods
uvx logshrink -- npm test
```
